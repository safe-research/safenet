## Claim

The sample sets `database = "sqlite:/var/lib/safenet/sentinel/data/storage.db"` and the handbook runs the image with a new named volume mounted at `/var/lib/safenet/sentinel/data`. `connect_sqlite` passes the parsed options to sqlx unchanged, and sqlx-sqlite 0.9.0 does not create a missing database file unless the URL says `mode=rwc` (`create_if_missing` defaults to false). On a fresh volume the file does not exist, so startup fails with SQLite error 14 ("unable to open database file"). Every Aegis sentinel starts fresh, so every operator who copies the sample hits this on first start. The integration test and the devnet never see it: they use `sqlite::memory:` or append `?mode=rwc` themselves. The failure is loud and the fix is one URL parameter, hence Low.

## Trigger

A new operator copies `sentinel.sample.toml`, fills in the addresses and key, and runs the image as in `docs/sentinel-handbook.md:82-90`. The volume is empty; `connect_sqlite` fails; the process exits before the driver starts.

## Considered and rejected

- Silent misbehaviour: none. The error is printed and the process stops, so no bond or vote is at stake; the cost is a failed first start and a support round.
- The operator may create the file by hand; nothing in the sample or handbook says to.
- The validator sample has the same line (`crates/validator/validator.sample.toml:26`); that file is in R6's assignment and is noted here only as the same pattern.
- Code age: the sample line is pre-existing (present at `fe9e84c`); not a migration issue, since it bites on a fresh node.

## Remediation options

1. Change the sample to `sqlite:/var/lib/safenet/sentinel/data/storage.db?mode=rwc` (and the validator sample likewise).
2. Set `create_if_missing(true)` in `connect_sqlite` for file databases. Fixes every config, but also silently creates a new empty database when the path is mistyped, which for the sentinel means forgetting earlier commitments; option 1 keeps that choice in the operator's config.

Tests to add: extend `config::tests::parses_sample_config` to connect to a temporary copy of the sample's database path.
