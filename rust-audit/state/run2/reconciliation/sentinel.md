### 1.1 The #914 statements, reconciled

These are **one fact, two bookkeeping choices**:

- Same code change: old `service.rs:410` `if block <= *commit_deadline` → `service.rs:423` `if block < *commit_deadline` (`git diff 3ec8bc5 fe9e84c -- crates/sentinel/src/service.rs`; run 1's `:418` is the branch line for the same hunk).
